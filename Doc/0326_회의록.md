# 📝 회의록

## 📌 1. 회의 개요
- **주제**: KKBox 데이터셋 기반 고객 이탈 예측 및 의사결정 지원 웹 서비스 기획  
- **목표**:  
  머신러닝 모델을 통해 고객 이탈을 예측하고,  
  결과를 **시각화 + 경영적 인사이트 제공 시스템**으로 구현
